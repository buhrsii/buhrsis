# Buhrsi's v0.27 – Freunde & gemeinsam putzen

Enthält:
- Freundschaften ausschließlich über Buhrsi-Code
- eingehende Freundschaftsanfragen mit Bestätigung
- Freundesliste ohne Chat, Standort oder freie Nachrichten
- Putzstatus wird während einer laufenden Runde geteilt
- Freunde werden etwa alle 5 Sekunden aktualisiert
- „MITPUTZEN“ startet direkt den vorhandenen 2-Minuten-Timer
- Status verfällt serverseitig nach 4 Minuten, falls ein Gerät unerwartet geschlossen wird

Vor dem Test einmal `supabase-v027-social.sql` vollständig im Supabase SQL Editor ausführen.

Die Push-Erinnerung bei geschlossenem/gesperrtem Handy ist bewusst noch nicht Teil dieses Schritts. Dafür folgt ein separater serverseitiger Push-Zusteller.
